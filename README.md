# Fake-News-Prediction
• Built an NLP-based binary text classification model to detect fake vs. real news articles using a labeled dataset of 20K+ entries\
• Designed a preprocessing pipeline using NLTK– stopword removal, Porter Stemming, and TF-IDF vectorization to convert raw news text into ML-ready numerical features\
• Trained a Logistic Regression classifier achieving 98.6% training accuracy and 97.9% test accuracy on unseen data
